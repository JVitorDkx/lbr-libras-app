# Mídias validadas de Libras

Adicione os arquivos nesta pasta mantendo estes nomes:

- `ola.mp4`
- `bom-dia.gif`
- `boa-tarde.mp4`
- `tchau.webp`

O FastAPI publica esta pasta em `/static/media/signs/`. Se um arquivo estiver ausente ou
falhar ao carregar, o frontend mostra o estado seguro de demonstração.

Antes de usar uma mídia como questão ou gabarito, registre a autoria, a autorização de uso e
a validação por profissional de Libras. Não inclua traduções automáticas do VLibras como
conteúdo pedagógico sem revisão humana.
